關於 MultiStream Hub

光暗主題

網站介紹

MultiStream Hub 是一個完全免費的多平台直播串流觀看工具，專為喜愛同時觀看多個直播的用戶設計。我們支援 Twitch 和 YouTube 兩大主流直播平台，讓您可以在同一個頁面上同時觀看多個直播串流，無需在多個分頁間切換。

本工具由個人開發者獨立開發維護，完全免費開放給所有人使用，無需註冊、無需付費，歡迎分享給您的朋友！

主要功能特色

🎥 多平台串流支援 支援 Twitch 和 YouTube 兩大直播平台，可同時觀看多個串流
🎨 多種布局模式 提供單一畫面、分割、網格、側邊聊天（雙欄、四格、單一聊天室）等多種布局選擇
💬 聊天室整合 整合 Twitch 和 YouTube 聊天室，可同時顯示多個聊天室
🔊 音量控制 獨立音量控制每個串流，並提供總音量控制功能
⭐ 收藏系統 收藏喜愛的串流，支援分類管理、Twitch 頻道搜尋、開台狀態檢測、匯出/匯入 JSON 檔案，快速載入收藏內容
📱 響應式設計 適配各種螢幕尺寸，提供流暢的使用體驗
🌐 多語言支援 支援繁體中文、簡體中文、英文、日文四種語言
🔒 安全可靠 採用 XSS 防護、CSP 安全策略，保護用戶安全
🔍 Twitch 頻道搜尋 支援 Twitch 頻道搜尋功能，快速找到喜愛的頻道
📡 開台狀態檢測 自動檢測收藏的 Twitch 頻道開台狀態
🎯 自動排版 Layout 自動排版功能，根據串流數量自動選擇最適合的布局
🔄 串流重新整理 支援串流重新整理功能，快速重新載入串流

技術特色

  • 純前端技術：使用純 HTML/CSS/JavaScript 開發，無需後端伺服器
  • 即時串流：整合 Twitch Embed API 和 YouTube IFrame API
  • 本地儲存：使用 localStorage 和 IndexedDB 保存設定和備份數據，支援匯出/匯入 JSON 檔案
  • SEO 優化：完整的 Meta 標籤和結構化數據
  • 效能優化：輕量級設計，快速載入
