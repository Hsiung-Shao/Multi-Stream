# 多來源直播分割器

支援 Twitch / YouTube 直播畫面自由分割、拖曳調整、音量控制 + 聊天室嵌入。

## 快速啟動
1. Clone repo: `git clone https://github.com/Hsiung-Shao/mutli-stream.git`
2. 開啟 `index.html` 直接用瀏覽器測試。
3. 部署：用 Cloudflare Pages 或 Vercel 一鍵上線。

## 功能
- 任意直播來源嵌入
- 布局預設（1~9 格）
- 獨立音量 + 總音量
- 收藏系統（localStorage）
- AdSense 廣告（每 30 分鐘彈出）

詳情見 `index.html` 註解。
