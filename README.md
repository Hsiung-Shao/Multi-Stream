# MultiStream Hub

![MultiStream Hub Logo](/icon.png)

**免費多平台直播串流觀看工具 | 同時觀看 Twitch & YouTube**

🔗 **正式網站連結:** [https://multistreaming.org/](https://multistreaming.org/)

MultiStream Hub 是一個現代化的網頁應用程式，專為直播愛好者設計。它允許用戶在一個介面中同時觀看多個 Twitch 和 YouTube 直播頻道，並整合了即時聊天功能，提供無縫的多工觀看體驗。無需註冊，完全免費。

## ✨ 主要功能

* **多平台支援**: 同時支援 Twitch 和 YouTube 直播串流。
* **多視窗佈局**: 靈活的網格佈局，可根據需求自由調整視窗大小與排列。
* **整合聊天室**: 內建 Twitch 和 YouTube 聊天室，不錯過任何互動訊息。
* **我的最愛**: 輕鬆收藏常看的頻道，支援標籤管理與分類，一鍵快速開啟。
* **極致效能**: 基於 React 與 Vite 構建，提供流暢的操作體驗。
* **現代化介面**: 採用 Shadcn/UI 與 TailwindCSS 設計，支援深色模式。
* **多語言支援**: 完整支援繁體中文、簡體中文、英文、日文及韓文。
* **隱私保護**: 無需註冊帳號，所有設定與收藏皆儲存於本地端 (Local Storage)。

## �️ 技術棧

本專案採用最新的前端技術構建：

* **核心框架**: [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
* **建構工具**: [Vite](https://vitejs.dev/)
* **樣式與 UI**: [TailwindCSS](https://tailwindcss.com/) + [Shadcn/UI](https://ui.shadcn.com/)
* **狀態管理**: [Zustand](https://github.com/pmndrs/zustand)
* **資料獲取**: [TanStack Query (React Query)](https://tanstack.com/query/latest)
* **圖表與視覺化**: Recharts
* **動畫**: Tailwind Animate

## � 快速開始

若您希望在本地端運行此專案，請按照以下步驟操作：

### 前置需求

* Node.js (建議 v18 或更高版本)
* npm 或 yarn

### 安裝步驟

1. **複製專案**

    ```bash
    git clone https://github.com/Hsiung-Shao/Multi-Stream.git
    cd multi-stream
    ```

2. **安裝依賴**

    ```bash
    npm install
    ```

3. **啟動開發伺服器**

    ```bash
    npm run dev
    ```

    伺服器啟動後，請在瀏覽器中開啟終端機顯示的 URL (通常為 `http://localhost:3000`)。

4. **建構生產版本**

    ```bash
    npm run build
    ```
